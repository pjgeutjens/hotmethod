# Hot Method repository guidance

This is the standalone Eleventy sister site for The Hot Method. Keep public
content in `src/_data/`, reusable markup in `src/_includes/`, and generated
output in `_site/`. Never edit `_site/` directly.

The visual language is a Hot Method adaptation of the shared Meridian source at
`../../design/meridian/`. Preserve its hierarchy, accessibility, semantic
tokens, restrained cards, and responsive behavior. Campaign-derived colors and
media provenance are documented in `docs/source-inventory.md`.

Do not assign an anonymous portrait to a graduate without an authoritative name
mapping. Do not commit, push, or deploy unless explicitly requested.
